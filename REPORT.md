# REPORT.md

## AI-setup

- IDE/редактор: VS Code
- Ассистент/агент: OpenCode-SourceCraft, работа через CLI (в терминале, без плагинов)
- Модель: sourcecraft-external/default (встроенная модель SourceCraft)

## Рассмотренные альтернативы

раньше использовал VSCODE+плагин SourceCraft, теперь меня интересует освоить работу через CLI, тем более, что на работе OpenCode с внутренней моделью qwen

## Неудачные попытки

- Backend сначала был сгенерирован на Express — переписан на NestJS после уточнения требований
- После перехода на NestJS остался старый `server/src/index.ts` — typecheck упал с ошибками про @types/express и неиспользуемый код; удалил файл, проверки прошли
- `npm install` в PowerShell упал из-за execution policy (npm.ps1 заблокирован) — запустил через `npm.cmd`
- Отправка POST-запроса через curl с экранированными кавычками в PowerShell исказила JSON — сохранил тело запроса в файл и передал через `--data-binary @file`
- Корневой скрипт `dev:server` не запускался — в `server/package.json` скрипт назывался `start:dev`, а не `dev`; добавил алиас `dev` в `server/package.json`

## Как чинили и к чему пришли

- Каждую проблему решали сразу по месту: удаление устаревшего файла, вызов npm через `npm.cmd`, передача JSON через файл, добавление алиаса скрипта
- В итоге все проверки прошли (typecheck, lint, build, тесты — 4 passed), приложение запущено, сценарий проверен через curl и в браузере

## Возникшие проблемы

- PowerShell execution policy блокирует запуск npm.ps1
- Вывод PowerShell в консоли агента отображался в испорченной кодировке (кракозябры), но на результат не влиял
- изначально постановку задачи записал в README.md. По ходу работы нужно было сформировать и заполнить README.md информацией о проекте и как его запускать. Без предупреждения был отредактирован README.md - в него был добавлен большой фрагмент текста. Пришлось отдельным действием переносить постановку из README.md в TASK.md.
- по какой-то причине когда заполняли с агентом пункт "AI-setup", то он предложил записать "VSCODE+плагин", но исправился, когда я спросил "знает-ли он, что мы работаем через CLI"
